# Book Club

Yrgo. Backend programming Part 2. Assignment 1. Spring Boot & Thymeleaf.

# Run the application

1. Open terminal

2. Navigate to the directory where you want this project to be

3. Run git clone https://github.com/gussannra/book_club.git

4. Run cd book_club

5. Run the program:

- Linux/mac: ./run.sh
- Windows Powershell: .\run.bat
- Windows Command Prompt: run.bat

# Test the application

http://localhost:8080/home : Show a greeting and date&time

http://localhost:8080/books : Show all books

http://localhost:8080/genre : Show all books and A search bar to look for books of specific genre

http://localhost:8080/genre?type=Fantasy : Show only fantasy books

http://localhost:8080/genre?type=Mystery : Show only mystery books

http://localhost:8080/genre?type=Non-fiction : Show only non-fiction books

http://localhost:8080/genre?type=Romance : Show only romance books
